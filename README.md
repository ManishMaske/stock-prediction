# Stock Price Prediction for Energy Sector Giants

This project focuses on analyzing historical stock data and predicting future stock price movements for three major multinational oil and gas corporations: **BP (BP)**, **Shell (SHEL)**, and **ExxonMobil (XOM)**. Using time-series analysis and machine learning techniques, the project explores patterns in historical data to forecast trends.

## 📊 Repository Structure

The repository contains the following files:
* `BP_data.csv`: Historical stock market dataset for BP.
* `SHEL_data.csv`: Historical stock market dataset for Shell.
* `XOM_data.csv`: Historical stock market dataset for ExxonMobil.
* `Stock prediction.ipynb`: A comprehensive Jupyter Notebook containing data preprocessing, exploratory data analysis (EDA), model training, and evaluation.

## 🛠️ Tech Stack & Libraries

The analysis and predictive models are built using Python and its standard data science ecosystem:
* **Data Manipulation:** `pandas`, `numpy`
* **Data Visualization:** `matplotlib`, `seaborn`
* **Machine Learning / Forecasting:** `scikit-learn` (and/or `statsmodels`, `keras`/`tensorflow` depending on your model implementation)

## 📈 Methodology

1.  **Data Loading & Cleaning:** Importing the CSV datasets, handling missing values, and formatting date indexes.
2.  **Exploratory Data Analysis (EDA):** Visualizing historical closing prices, trading volumes, and rolling averages to identify overarching market trends.
3.  **Feature Engineering:** Creating technical indicators (such as Moving Averages, RSI, or lagged features) to optimize predictive accuracy.
4.  **Model Training:** Fitting time-series or regression models to learn from historical patterns.
5.  **Evaluation:** Measuring model performance using metrics such as Mean Squared Error (MSE), Root Mean Squared Error (RMSE), or Mean Absolute Error (MAE).
